# Local mechanical checks

From this skill's `assets/lint` directory, install exact npm dependencies with `npm ci --ignore-scripts --no-audit --no-fund --registry=https://registry.npmjs.org/`. The committed lock records every transitive integrity value. Run the same checker locally and in CI; it never installs dependencies implicitly.

- Japanese: textlint 15.8.0, Japanese preset 10.0.4. A small subset detects sentence length, adjacent particles/conjunctions and invisible/invalid characters. Ordinary versus polite voice is not forced; uncertainty is not removed.
- English: Vale 3.25.1, built-in repetition/spelling plus a reviewed local vocabulary. No remote style packages or API. Official Linux x86_64 archive: https://github.com/vale-cli/vale/releases/download/v3.25.1/vale_3.25.1_Linux_64-bit.tar.gz ; SHA256 `4bf5c5176b682b1da0830f471584d3494f1c2e27ee3029e1ad6f6661d4962182`. Place only the verified `vale` binary in `assets/lint/.tools/`.
- LanguageTool: optional local supplement. Japanese is supported, but has no spellcheck; do not call it unsupported or equivalent to English. Java and the jar are not installed here. The checker reports NOT_INSTALLED unless explicit local CLI jar and Java are available; no cloud fallback. See https://dev.languagetool.org/languages and https://dev.languagetool.org/http-server .

The checker masks frontmatter, fenced/indented code, inline code and link destinations without modifying the original. Link labels remain prose; source URLs need a separate technical/link review. It records input/config hashes, actual tool version, exit code and findings without full draft text or host paths. Reports are immutable: choose a fresh JSON output path. Suppress a false positive narrowly with article SHA, rule, exact finding fingerprint and reason in a local suppression JSON. Never broadly waive a technical or privacy blocker. Lint is advisory at the finding level; missing primary tooling is MAJOR, unavailable optional LanguageTool is a recorded non-blocking limitation.

The review validator checks supplied cycle values 1–2 and distinct assignment identities. The orchestrator records the actual cycle history and role independence; this CLI is not a scheduler or an authorization authority.
