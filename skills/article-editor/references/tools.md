# Local mechanical checks

From this skill's `assets/lint` directory, install exact npm dependencies with `npm ci --ignore-scripts --no-audit --no-fund --registry=https://registry.npmjs.org/`. The committed lock records every transitive integrity value. Run the same checker locally and in CI; it never installs dependencies implicitly.

- Japanese: textlint 15.8.0, Japanese preset 10.0.4 and @textlint-ja/textlint-rule-preset-ai-writing 1.7.0 (MIT, requires textlint >=15.1.0). A small subset detects sentence length, adjacent particles/conjunctions and invisible/invalid characters. Ordinary versus polite voice is not forced; uncertainty is not removed.
- English: Vale 3.25.1, built-in repetition/spelling plus a reviewed local vocabulary. No remote style packages or API. Official Linux x86_64 archive: https://github.com/vale-cli/vale/releases/download/v3.25.1/vale_3.25.1_Linux_64-bit.tar.gz ; SHA256 `4bf5c5176b682b1da0830f471584d3494f1c2e27ee3029e1ad6f6661d4962182`. Place only the verified `vale` binary in `assets/lint/.tools/`.
- LanguageTool: optional local supplement. Japanese grammar rules ran in the local smoke, but Japanese spellcheck is unavailable; do not call it equivalent to English. OpenJDK 25.0.4.1 is installed. The 6.6 ZIP is blocked by Cloudflare1010; do not impersonate clients or bypass that restriction. Official Maven CLI6.8 plus explicit en/ja modules is the local alternative. Four Java25/-Xmx512m public examples passed: EN_A_VS_AN and KOREWA were detected in errors; their clean controls had no findings. This is not a long-article benchmark or a full compatibility guarantee. Record smoke evidence separately from each article check. The checker reports NOT_INSTALLED when the local CLI jar is absent, otherwise NOT_RUN; it never invents an execution. No cloud fallback. See https://dev.languagetool.org/languages and https://dev.languagetool.org/http-server .

The primary linters receive native Markdown with only complete frontmatter lines blanked. textlint uses pinned node-types filter1.1.0 to ignore code, metadata, HTML and links/images/definitions; link labels are also excluded in Japanese and need manual review. Vale uses its native code/URL handling. Whitespace-masked evidence projections are never fed back as Markdown because they can accidentally create indented code. The original is never modified. It records input/config hashes, actual tool version, exit code and findings without full draft text or host paths. Reports are immutable: choose a fresh JSON output path. Suppress a false positive narrowly with article SHA, rule, exact finding fingerprint and reason in a local suppression JSON. Never broadly waive a technical or privacy blocker. Lint is advisory at the finding level; missing primary tooling is MAJOR, unavailable optional LanguageTool is a recorded non-blocking limitation.

The review validator checks supplied cycle values 1–2 and distinct assignment identities. The orchestrator records the actual cycle history and role independence; this CLI is not a scheduler or an authorization authority.

Candidate identities, scope and adoption decisions are recorded in [candidate review](candidates.md). Noslop v26.10.114 is available for explicit Japanese sanitized-copy checks. The adapter verifies its exact binary digest, executes fixed private input/executable copies and uses only `check --no-config --dict bundled --genre tech --format json --fail-on never`. It never installs a dictionary, hook, server or global Skill. Optional failure remains visible without blocking independent review.

Normalize textlint UTF16 and noslop UTF8 offsets to Unicode source positions. Merge only the known HYPE rule pair at the same position and lexical span (allowing one terminal attributive な); retain both original spans/messages/severities. Other duplicates require matching normalized messages and position. Fingerprints include every source, so an old suppression cannot silently cover an added source. The measured fixture has four raw candidates / three groups; no broader semantic equivalence is claimed.

## On-demand LanguageTool

Use the locally provisioned official6.8 jars with `java -Xmx512m -cp 'LOCAL_TOOL_ROOT/lib/*' org.languagetool.commandline.Main --json -c UTF-8 -l en-US PUBLIC_EXAMPLE.txt` (or `-l ja`). Use an authorized local copy only. No server, listener or API is needed. Availability is not execution; save the exact Java/tool versions, input hash, exit code, JSON and limitations. Japanese grammar and Japanese spellcheck are different capabilities. Source/license details and measured language support belong in candidate review; do not infer all grammar coverage from four smoke examples.

## Review fingerprint semantics

`review.json.mechanical_sha256` binds canonical mechanical-report data: SHA256 of UTF8 `json.dumps(report, sort_keys=True, ensure_ascii=False)` with Python defaults. It is intentionally different from the hash of the indented JSON file. The wrapper also captures and rechecks raw input bytes and binds the raw mechanical/review bytes in exported execution evidence. Keep canonical-data and raw-file hashes named separately in diagnostics.

Before manual LanguageTool invocation, verify the local jars against the captured artifact inventory. The checker’s availability flag is not an integrity check or an execution claim.
